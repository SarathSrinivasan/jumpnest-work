# JUMPNEST Premium Frontend

Separate-page frontend for a premium indoor trampoline and soft-play center.

Pages: Home, Home 2, Attractions, Passes, Birthdays, About, Blogs, blog articles, Contact & Location, Parent Login, Parent Sign Up, Parent Dashboard, Admin Dashboard, and 404.

Theme and RTL preferences persist in localStorage. Portal links provide one-click access to parent login/signup, parent dashboard and admin dashboard. Login, signup and admin dashboard are intentionally password-free frontend demo screens.

Open `index.html` directly in a browser; no server or build step is required.
